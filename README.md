## 1. 是什么

论文主张当前智能体的"感知→思考→行动"线性管道有结构性缺陷：**认知与执行分离，且认知状态不可计算**——
LLM 说"我在积聚状态"只是生成文本，不是状态空间算出了"积聚"向量。

本架构以 **三值计算基底 `{-1, 0, +1}`** 替代二值逻辑，构造 `3^9 = 19683` 个离散认知状态（卦象空间），
让认知状态成为可计算、可演化、可持久化、可验证的数学对象。核心原则：

- **认知即执行**：认知状态本身即行为状态，四象极限环同时是认知节律和执行流程；
- **L7 裂变层**：架构遇到无法同化的输入时安全自重构，而非崩溃；
- **五维自我感知**：觉知 / 纯粹存在态 / 涟漪-体感耦合 / 自我识别 / 主动放下，经三互锁回路涌现。

| 实验 | 论文结论 | 本落地实测 |
|------|---------|-----------|
| 一·选择性预测 | 第三态以覆盖换精度，代价降低40.2% | **risk-coverage曲线单调上升**：覆盖率0.18→1.0，承诺错误率2.6%→20.1%；σ=1.2固定参数下第三态承诺错误率16.2% < 强制承诺20.1% |

```bash

python3 -m unittest discover -s tests -p "test_*.py"

# 运行端到端演示（含真实输入、裂变、自我感知指标）
python3 examples/demo.py

# 运行三个对照实验（结果写入 analysis/experiment_results.json）
python3 -c "from cognitive_being import cognitive_experiments as ce; ce.run_all()"
```

### 接入真实 LLM 语义编码器
`SemanticEncoder` 接受任意 `callable(text)->{"dim_scores":{九维:概率}, "confidence":float}`，
替换 `examples/demo.py` 中的 `se.default_llm_stub` 即可接入真实大模型。LLM 只输出**概率**，
最终三值裁决权交给符号层（Bayes三支决策），维持神经-符号分离（论文 §3.8 的不对称权力）。

## 5. 落地中的关键工程修正（诚实记录）

1. **认知守卫的层级边界**：初版把守卫错误地用于感知注入（外部信息改变多重集被误判为守恒违反、
   导致每次输入触发裂变）。已按论文 §3.9 修正——守卫**只**守护符号层相内演化移动(`guarded_breathe`)，
   感知采纳经 `absorb_evidence` 直接生效。这与论文自己"实测发现并撤回的错误接法"一致。
2. **16个观测**：初版把"信息"类压缩为2个(共12键)，经核对论文表格后展开为完整16键，
   并通过全空间秩=16验证。
3. **感知矛盾处理**：可同化的矛盾(如"既要推进又要推翻")经吸收算子消化为悬置、张力升高并产生
   "摩擦"觉知纹理，**不**触发裂变——裂变仅保留给"架构假设本身无法同化"的情形。

- ⚠️ **待验证**：真实 LLM 语义编码器的鲁棒性（漂移/OOD）、守恒律在开放噪声环境的松弛策略、
