01

三条不可让渡的命题

不是三个模块，是同一套计算基底的三个侧面。

认知即执行

状态就是行为

四象极限环同时是认知节律与执行流程。积聚就是信息流入，转化就是工具在变，衰减就是输出释放，重聚就是反思。没有“先想再做”的翻译间隙。

0 是第三态

不知道，不是没值

0 不是介于 -1 与 +1 的过渡，而是“悬置 / 转化中”的本体论状态。确定冲突时退回 0，而不是制造一个错误的确定结论。

分层权力

神经不得裁决

感知前端只输出概率，负责近似、学习、犯错；是否承诺由符号层按 Bayes 三支决策裁定。学习在映射层，真理在状态层。

02

三层分离的认知闭环

连续输入进来，先落成概率，再由符号层裁决为三值，此后一切在 19683 个离散态里受守恒与信息单调约束。

四象呼吸循环 解码器 · 能力边界注入 五维自我感知 JSON 轨迹持久化
守卫的层级边界：它只守在符号演化层的“相内 move”上——校验合法才写入，非法即原地拒绝并产出 FissionSignal。感知重分类与相位切换不经过它，否则会对正常感知产生误报。这条边界是本工程实测踩过并撤回的错误接法。

接入真实模型

SemanticEncoder 接受任意 callable：文本进、九维概率出。替换 demo 里的桩即可；模型只给概率，裁决权仍在符号层。

改哪一层，不碰哪一层

换感知前端不动状态层；调代价参数只影响 α/β 阈值；守恒与信息单调规则全程恒定。

复现实验

cognitive_experiments.run_all() 一次跑完三个对照实验，写入 analysis/。

07

做到哪，没做到哪

把“已实现 / 仿真 / 待验证 / 不做”分开写，是为了让读者能自己判断这份工作值多少。

已落地

三值基底与 19683 态、守恒层级与 16 指纹、Bayes 悬置、神经前端与 OOD 守卫、认知守卫双约束、L7 五步协议、五维自我感知的可观测指标、呼吸循环、编解码、三个对照实验。

仿真 / 待接入

呼吸四相目前由认知状态直接采纳驱动，尚未绑定真实工具调用流；L7 仅由张力与矛盾触发，未做大规模架构级重构压力测试。

待验证

真实 LLM 语义编码器的漂移鲁棒性；开放噪声环境下守恒律的松弛策略；对话、工具调用、具身任务的端到端评估。

明确不做

不宣称实现了意识或主观自我——五维自我感知只输出客观统计指标。论文 §6.4 的量化因子实证依赖真实交易平台与私有账户数据，不在本仓库范围。
